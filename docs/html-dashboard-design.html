Design note

HTML Dashboard Design

The company kit works as a static HTML dashboard with editable logs, sprint pages, release pages, workflow playbooks, role profiles, persistent navigation, light/dark mode, and a professional Small Project Mode default.

Structure

One shared stylesheet supports static HTML pages under agents, logs, sprints, workflows, templates, and docs.

Navigation

A shared script adds the same left panel to every page and marks the active page.

Theme

The sidebar includes a light/dark toggle that saves the selected theme in local storage.

Default Mode

Small Project Mode is the default when no mode is mentioned: Orion, one specialist developer, and Scout.

Logging

Activity, decision, risk, QA, and release logs provide the source material for sprint reports.

Agent Names

Each role includes an optional codename badge for fun while preserving the professional role identity.

Design Constraints

  • No build system.
  • No database.
  • No required server.
  • Works by opening index.html in a browser.
  • Plain HTML files remain easy for agents to edit.
