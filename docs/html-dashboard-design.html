Design note

HTML Dashboard Design

The company kit now works as a static HTML dashboard with editable logs, sprint pages, release pages, workflow playbooks, and role profiles.

Structure

One shared stylesheet supports static HTML pages under agents, logs, sprints, workflows, templates, and docs.

Logging

Activity, decision, risk, QA, and release logs provide the source material for sprint reports.

Agent Names

Each role includes an optional codename badge for fun while preserving the professional role identity.

Design Constraints

  • No build system.
  • No database.
  • No required server.
  • Works by opening index.html in a browser.
  • Plain HTML files remain easy for agents to edit.
