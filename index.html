If the user does not mention a mode, run Small Project Mode. If the work appears broad, release-sensitive, security-sensitive, or cross-system, ask which mode to use before starting.

When To Add Specialists

  • Security: auth, secrets, user data, permissions, payments.
  • DevOps: CI/CD, servers, deployments, observability.
  • Database: schema, migrations, analytics, data cleanup.
  • Product Owner: unclear user workflow or acceptance criteria.
  • Release Manager: production release, public changelog, rollback.
  • AI Automation: prompts, agents, tools, LLM workflows.

Logging Rule

Every active role logs what changed, what was decided, what was verified, and what remains open before handing off.
