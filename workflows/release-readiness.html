Workflow

Release Readiness

Use before shipping a completed change.

Gate Checklist

  • Scope is clear.
  • Implementation is complete.
  • Code review is complete.
  • QA passed or risk is accepted.
  • Security review is complete when required.
  • Deployment and rollback steps are known.
  • Release notes are ready.
  • Known risks are documented.

Decision

Ship

Ready for release.

Hold

Blocker remains.

Ship with accepted risk

Non-blocking risk is documented and accepted.
