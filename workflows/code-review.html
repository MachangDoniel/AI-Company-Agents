Code Review

Use after implementation and before QA or release.

Prioritize

  • Bugs
  • Regressions
  • Security and privacy risk
  • Broken contracts
  • Meaningful test gaps

Avoid Churn

  • Pure style preferences
  • Unrelated refactors
  • Alternative designs without material gain
